# VEXORA

صفحة VEXORA التعريفية ومعرض النماذج التجريبية للخدمات الرقمية.

## هيكل المشروع

- `index.html` — بنية الصفحة ومحتواها العربي/الإنجليزي.
- `assets/styles.css` — التنسيقات والاستجابة للأجهزة.
- `assets/app.js` — الترجمة، التنقل، ونموذج التواصل عبر WhatsApp.
- `assets/logos/` — شعارات النماذج المحلية، دون عرض روابطها داخل البطاقات.
- `assets/og-image.svg` — صورة المشاركة الاجتماعية.
- `scripts/validate.py` — فحص ثابت بسيط قبل النشر.

## النشر

الموقع مصمم للعمل مباشرة على GitHub Pages من الفرع `main`. شغّل `python3 scripts/validate.py` قبل نشر أي تغيير.
